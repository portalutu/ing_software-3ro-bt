# Ingeniería de Software - 3º Año EMT (2026)

Repositorio de apoyo para la materia, pensado para centralizar material teórico, plantillas de trabajo y documentos de referencia para proyectos de software.

## Objetivo

Este repositorio reúne en un solo lugar:

- material teórico para clase;
- plantillas listas para completar;
- documentos de apoyo sobre Git, Markdown y gestión de proyectos;
- ejemplos que conectan requerimientos, historias de usuario, backlog y sprint planning.

## Recorrido sugerido para estudiantes

Un recorrido posible para usar este repositorio durante el curso es:

1. Leer los conceptos generales en `Teoricos/`.
2. Entender cómo entrevistar al cliente en [entrevistas.md](Teoricos/entrevistas.md).
3. Convertir necesidades en historias de usuario con [user-stories.md](Teoricos/user-stories.md).
4. Armar y priorizar el producto con [backlog.md](Teoricos/backlog.md).
5. Planificar una iteración con [sprint-planning.md](Teoricos/sprint-planning.md).
6. Apoyarse en las plantillas de `templates/` para documentar el proyecto real.

## Relación entre algunos documentos

Los materiales teóricos agregados están pensados para mostrar una secuencia de trabajo:

`entrevista del cliente -> requerimientos -> historias de usuario -> backlog -> sprint planning`

Esto permite que los estudiantes no vean cada artefacto como un documento aislado, sino como parte del proceso completo de desarrollo.

## Uso recomendado en clase

- Utilizar `Teoricos/` como base conceptual y de ejemplos.
- Usar `templates/` como documentos a completar por equipo.
- Complementar con `documentos/` cuando se necesiten guías prácticas de redacción o control de versiones.

## Nota

Este repositorio puede seguir creciendo con nuevos materiales teóricos, ejemplos de backlog, casos de estudio y guías de trabajo para acompañar la materia durante el año.
